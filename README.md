# Проект Carts

## Описание:

Проект Carts - это код питона для банка

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/Choso94/Proect.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Использование:

1. Ввод данных карт
2. Их шифравание
3. generator создает номера, сортирует списки

# Пример использования:
 
Вы вводите инфу о карте Maestro 1596837868705199 и программа выдаёт вам Maestro 1596 83** **** 5199

Или вы вводите информацию о счёте Счет 73654108430135874305 и программа выдаёт Счет **4305

Generator вы 1 вводите транзакции 2 вводите описание 3 создаете границы
